Problem

ปัญหาหลักที่ผมพบระหว่างการทำงานคือข้อจำกัดด้านการตกแต่งของ HTML และ CSS ซึ่งทำให้ไม่สามารถออกแบบเว็บไซต์ให้สมบูรณ์ตามที่ตั้งใจไว้ได้ทั้งหมด เช่น ต้องการกรอบที่มีลวดลายเฉพาะหรือไอคอนบางรูปแบบ แต่ CSS ไม่สามารถสร้างกราฟิกลักษณะดังกล่าวได้ นอกจากนี้การจัดวางขนาดองค์ประกอบต่างๆ ให้ลงตัวก็เป็นสิ่งที่ค่อนข้างท้าทายเช่นกัน

Understanding

ผมเข้าใจว่าปัญหานี้ไม่ได้เกิดจากข้อจำกัดของเว็บไซต์โดยตรง แต่เป็นข้อจำกัดของภาษาที่เลือกใช้ในงานชิ้นนี้ เนื่องจาก A1 เป็นโจทย์ที่เน้นฝึกความเข้าใจพื้นฐานของ HTML และ CSS เพื่อปูพื้นฐานให้แน่น จึงมีขอบเขตของโจทย์ที่จำกัดไว้ในระดับนี้

"หากได้พัฒนางานนี้ต่อ อยากปรับปรุงหรือเพิ่มอะไร ?"

หากมีโอกาสได้พัฒนางานนี้ต่อ ผมตั้งใจจะเพิ่มไอคอนและ GIF เข้ามาในหน้าเว็บ พร้อมปรับกราฟิกให้สวยงามและกลมกลืนกับตัวเว็บไซต์มากยิ่งขึ้น เช่น การเพิ่ม Taskbar ที่เคลื่อนไหวตามหน้าจอและสามารถโต้ตอบโต้กับผู้ใช้ได้ หรือปรับให้แต่ละหัวข้อสามารถกดเพื่อแสดงผลแบบ Pop-up แทนการแสดงเนื้อหาทั้งหมดในหน้าเดียว นอกจากนี้ยังอยากออกแบบให้มีกรอบที่กำหนดขอบเขตการจัดวางชัดเจนขึ้น รวมถึงจัดระเบียบไฟล์ในโปรเจกต์ให้เป็นหมวดหมู่และดูสะดวกต่อการค้นหามากกว่าเดิม
